# capLG - 串口日志采集工具

## 版本信息
- 版本: v2.1
- 打包日期: 2024
- 更新: 新增模组控制功能

## 功能特性

### 核心功能
1. **串口通信**
   - 自动检测可用串口
   - 支持多种波特率
   - 实时日志显示
   - 快速发送（文本/HEX/二进制）

2. **图片监控**
   - 自动监控指定目录的图片
   - 实时预览图片
   - 历史图片记录（最多10张）
   - 支持多图片显示

3. **日志搜索**
   - 快捷键 Ctrl+F 快速搜索
   - 实时高亮匹配项
   - 支持区分大小写
   - 支持全字匹配
   - 上下导航匹配项

4. **保存功能**
   - 保存日志和图片
   - 三种保存策略：全部日志/最近N行/从关键词开始
   - 自动按规则命名
   - 快速打开保存目录

5. **模组控制** ⭐ 新增
   - 独立模组串口连接
   - 获取模组版本号
   - 完整协议通信（同步、校验、解析）
   - 实时响应显示
   - 支持扩展更多指令

6. **主题切换**
   - 深色模式
   - 浅色模式
   - 一键切换

7. **窗口布局**
   - 左右分割可调节
   - 上下分割可调节（图片预览和保存控制）
   - 灵活适应不同屏幕

## 文件列表

### 源代码文件
- `window_pyside6_unified_v2.py` - 主程序
- `config_manager.py` - 配置管理模块
- `log_search_pyside6.py` - 日志搜索窗口（旧版，已集成到主窗口）
- `serial_sender_pyside6.py` - 串口发送窗口

### 打包文件
- `build_capLG.spec` - PyInstaller 打包配置

```
PySide6 >= 6.0.0
pyserial >= 3.5
watchdog >= 2.0.0
```

## 安装依赖
```bash
pip install PySide6 pyserial watchdog
```

## 运行源码
```bash
python window_pyside6_unified_v2.py
```

## 打包说明

### Windows 打包
1. 安装 PyInstaller：
   ```bash
   pip install pyinstaller
   ```

2. 运行打包脚本：
   ```bash
   build.bat
   ```
   
   或手动打包：
   ```bash
   pyinstaller build_capLG.spec --clean
   ```

3. 打包完成后，可执行文件位于 `dist\capLG.exe`

### 打包参数说明
- `--onefile`: 打包成单个可执行文件
- `--noconsole`: 不显示控制台窗口（GUI 模式）
- `--clean`: 清理临时文件
- `--name capLG`: 指定程序名称

## 使用说明

### 1. 串口连接
- 选择串口和波特率
- 点击"连接串口"
- 状态栏显示连接状态

### 2. 启用监控
- 点击"设置"配置监控目录、保存目录和测试版本
- 点击"启用监控"开始监控图片
- 检测到新图片会自动显示在右侧预览区

### 3. 搜索日志
- 方式1: 在日志中选中文字后按 Ctrl+F
- 方式2: 直接按 Ctrl+F 然后输入搜索内容
- 使用 ▲▼ 按钮或 Enter/Shift+Enter 导航
- 按 Esc 关闭搜索栏

### 4. 保存数据
- 填写测试信息（类型、注册人员、手机、备注）
- 选择日志保存策略
- 点击"保存当前图片和日志"

### 5. 历史图片
- 下拉框查看历史图片
- 切换选择要保存的图片
- 点击"清空历史"清除所有记录

### 6. 主题切换
- 点击工具栏的主题按钮
- 🌙 深色模式 / ☀️ 浅色模式

### 7. 模组控制 ⭐ 新增
- 在右侧"模组控制"面板选择模组串口和波特率
- 点击"🔌 连接模组"建立连接
- 点击"📋 获取版本号"获取模组固件版本
- 在"响应信息"区域查看指令发送和响应结果
- 详细说明见 [模组控制功能说明.md](模组控制功能说明.md)

## 快捷键
- `Ctrl+F`: 打开搜索
- `Esc`: 关闭搜索
- `Enter`: 下一个匹配项
- `Shift+Enter`: 上一个匹配项

## 配置文件
程序会在用户目录下创建配置文件：
- Windows: `C:\Users\<用户名>\.capLG_config.json`

配置内容包括：
- 串口设置
- 监控目录
- 保存目录
- 测试版本
- 上位机程序路径
