# capLG - 串口日志采集工具

## 版本信息
- 版本: v2.2
- 打包日期: 2024
- 更新: 新增快捷命令、图片查看器、性能优化

## 功能特性

### 核心功能
1. **串口通信**
   - 自动检测可用串口
   - 支持多种波特率
   - 实时日志显示（性能优化，支持5000行缓存）
   - 快速发送（文本/HEX/二进制）
   - 快捷命令功能（自定义常用命令一键发送）⭐ 新增
   - 快速发送区域可折叠 ⭐ 新增

2. **图片监控**
   - 自动监控指定目录的图片
   - 实时预览图片（水平排列显示）
   - 历史图片记录（最多10张）
   - 支持多图片显示
   - 双击图片打开独立查看器 ⭐ 新增

3. **图片查看器** ⭐ 新增
   - 缩放功能：放大、缩小、适应窗口、实际大小
   - 旋转功能：顺时针、逆时针旋转（90度）
   - 翻转功能：水平、垂直翻转
   - 矩形框绘制：支持智能输入 `[left, top, right, bottom]` 格式
   - 滚动查看：放大后可滚动查看图片细节
   - 快捷键支持：Ctrl++ / Ctrl+- / Ctrl+0 / Ctrl+1 等

4. **日志搜索**
   - 快捷键 Ctrl+F 快速搜索
   - 实时高亮匹配项
   - 支持区分大小写
   - 支持全字匹配
   - 上下导航匹配项

5. **保存功能**
   - 保存日志和图片
   - 三种保存策略：全部日志/最近N行/从关键词开始
   - 自动按规则命名
   - 快速打开保存目录

6. **模组控制**
   - 独立模组串口连接
   - 获取模组版本号
   - 完整协议通信（同步、校验、解析）
   - 实时响应显示
   - 支持扩展更多指令

7. **主题切换**
   - 深色模式
   - 浅色模式
   - 一键切换

8. **窗口布局**
   - 左右分割可调节
   - 上下分割可调节（图片预览和保存控制）
   - 灵活适应不同屏幕

9. **性能优化** ⭐ 新增
   - 日志批量处理，减少UI更新频率
   - 自动清理前导空格
   - 限制最大日志行数（5000行）

## 文件列表

### 源代码文件
- `window_pyside6_unified_v2.py` - 主程序
- `config_manager.py` - 配置管理模块

### 打包文件
- `build_capLG.spec` - PyInstaller 打包配置

```bash
pip install PySide6 pyserial watchdog
```

## 运行源码
```bash
python window_pyside6_unified_v2.py
```

## 打包说明

### Windows 打包
1. 安装 PyInstaller：
   ```bash
   pip install pyinstaller
   ```

2. 运行打包脚本：
   ```bash
   build.bat
   ```
   
   或手动打包：
   ```bash
   pyinstaller build_capLG.spec --clean
   ```

3. 打包完成后，可执行文件位于 `dist\capLG.exe`

### 打包参数说明
- `--onefile`: 打包成单个可执行文件
- `--noconsole`: 不显示控制台窗口（GUI 模式）
- `--clean`: 清理临时文件
- `--name capLG`: 指定程序名称

## 使用说明

### 1. 串口连接
- 选择串口和波特率
- 点击"连接串口"
- 状态栏显示连接状态

### 2. 快速发送 ⭐ 新增
- 点击"➕ 添加命令"按钮打开快捷命令管理窗口
- 添加常用命令（支持文本、HEX、二进制格式）
- 在主界面快速发送区域点击对应按钮一键发送
- 快速发送区域支持折叠/展开

### 3. 启用监控
- 点击"设置"配置监控目录、保存目录和测试版本
- 点击"启用监控"开始监控图片
- 检测到新图片会自动显示在右侧预览区（水平排列）

### 4. 图片查看 ⭐ 新增
- 双击任意图片打开独立查看器窗口
- 使用工具栏按钮或快捷键进行操作：
  - 🔍+ / 🔍- : 放大/缩小
  - 📐 : 适应窗口
  - 1:1 : 实际大小
  - ↺ / ↻ : 旋转
  - ⇄ / ⇅ : 翻转
  - 🔄 : 重置所有变换
- 矩形框绘制：
  - 在"快速输入"框中粘贴坐标，如 `[50, 100, 300, 400]`
  - 按回车或点击"📋 解析"自动绘制红色矩形框
  - 点击"🗑️ 清除"移除矩形框

### 5. 搜索日志
- 方式1: 在日志中选中文字后按 Ctrl+F
- 方式2: 直接按 Ctrl+F 然后输入搜索内容
- 使用 ▲▼ 按钮或 Enter/Shift+Enter 导航
- 按 Esc 关闭搜索栏

### 6. 保存数据
- 填写测试信息（类型、注册人员、手机、备注）
- 选择日志保存策略
- 点击"保存当前图片和日志"

### 7. 历史图片
- 下拉框查看历史图片
- 切换选择要保存的图片
- 点击"清空历史"清除所有记录

### 8. 主题切换
- 点击工具栏的主题按钮
- 🌙 深色模式 / ☀️ 浅色模式

### 9. 模组控制
- 在右侧"模组控制"面板选择模组串口和波特率
- 点击"🔌 连接模组"建立连接
- 点击"📋 获取版本号"获取模组固件版本
- 在"响应信息"区域查看指令发送和响应结果
- 详细说明见 [模组控制功能说明.md](模组控制功能说明.md)

## 快捷键

### 日志搜索
- `Ctrl+F`: 打开搜索
- `Esc`: 关闭搜索
- `Enter`: 下一个匹配项
- `Shift+Enter`: 上一个匹配项

### 图片查看器 ⭐ 新增
- `Ctrl++`: 放大
- `Ctrl+-`: 缩小
- `Ctrl+0`: 适应窗口
- `Ctrl+1`: 实际大小
- `Ctrl+L`: 逆时针旋转
- `Ctrl+R`: 顺时针旋转
- `Ctrl+H`: 水平翻转
- `Ctrl+V`: 垂直翻转

## 配置文件
程序会在用户目录下创建配置文件：
- Windows: `C:\Users\<用户名>\.capLG_config.json`

配置内容包括：
- 串口设置
- 监控目录
- 保存目录
- 测试版本
- 上位机程序路径
